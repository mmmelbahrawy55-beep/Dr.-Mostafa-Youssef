# د. مصطفى يوسف — Dr. Mostafa Youssef

موقع كامل لاستشاري تغذية علاجية ومدرب لياقة: عربي أولاً (RTL) مع دعم الإنجليزي، حسابات عملاء، اشتراكات مدفوعة عبر **فودافون كاش / إنستاباي** بفحص إشعار التحويل، ولوحة تحكم إدارية كاملة للمحتوى والعملاء والمدفوعات والإعدادات.

## التشغيل

```bash
npm install
npm run dev        # API :4000 + الواجهة :5173  (http://127.0.0.1:5173)
npm run dev:api    # السيرفر فقط
npm run dev:web    # الواجهة فقط
npm run build      # tsc + vite build → dist/
npm run preview    # معاينة نسخة الإنتاج
npm run typecheck  # فحص أنواع TypeScript
```

> الملفات البيانية (`data/app.db`، `data/jwt-secret`، `data/screenshots/`، `data/uploads/`) مش موجودة في الـ repo — بتتعمل تلقائياً أول تشغيل.

## المحتوى

- `/` الرئيسية · `/about` · `/services` · `/programs` · `/results` · `/calculator` · `/blog` · `/contact` · `/privacy` · `/terms` · 404
- حساب العميل: `/register` · `/login` · `/account` (الباقة الحالية، الدفعات، الصور المرفوعة، الملف الشخصي)
- الاشتراك: `/subscribe/:programId` (اختيار الخطة → فودافون كاش/إنستاباي → رفع إشعار التحويل → تفعيل)
- لوحة التحكم: `/admin` (نظرة عامة، المدفوعات، العملاء، الاشتراكات، محتوى الموقع، نصوص الموقع، الرسائل، الصور، الإعدادات، سجل العمليات)

## نظام الدفع

1. العميل يختار الباقة ويُدخل مبلغ العملية + رقم المرسل + رقم عملية التحويل ويرفع صورة الإيصال.
2. الخادم يتحقق من: كون الملف صورة حقيقية، الأبعاد والحجم، تطابق المبلغ مع سعر الباقة، صيغة رقم المحفظة، رقم العملية، ومنع تكرار نفس الصورة أو نفس المرجع.
3. لو كل شيء سليم والتفعيل التلقائي مفعّل → الاشتراك يتفعّل فوراً (`auto_approved`)، وإلا يدخل قيد المراجعة (`pending`).
4. المدير يراجع الصورة ويوافق أو يرفض مع ملاحظة، ويظهر أثر العملية في `سجل العمليات`.

المبالغ محفوظة كأعداد صحيحة بالجنيه المصري، والتواريخ بصيغة ISO.

## لوحة التحكم

- **نظرة عامة**: الإيرادات (الإجمالي / النهار / الشهر)، المدفوعات المعلقة، العملاء، الاشتراكات النشطة والقريبة من الانتهاء، ورسم بياني لآخر 6 شهور.
- **المدفوعات**: فلترة وبحث، معاينة صورة الإيصال في نافذة، موافقة/رفض مع ملاحظة.
- **العملاء**: إنشاء/تعديل/إيقاف، تفاصيل شاملة (اشتراكات، دفعات)، منح اشتراك يدوي.
- **المحتوى**: تحرير كل المجموعات (البرامج، الخدمات، آراء العملاء، النتائج، المقالات، الأسئلة، المؤهلات) بالعربية والإنجليزية.
- **نصوص الموقع**: تحرير أي نص في الموقع مع تجاوز قيم النسخة الأصلية (overrides) وإعادة تعيينها.
- **الرسائل**: وارد رسائل نموذج التواصل مع رد واتساب وحذف.
- **الصور والوسائط**: رفع ومراجعة ونسخ الرابط وحذف.
- **الإعدادات**: بيانات التواصل، أرقام المحافظ، التعليمات، إعلان علوي، صورة الغلاف، وتفعيل/تعطيل الموافقة التلقائية.
- **سجل العمليات**: كل عملية بفعلها ومنفّذها ووقتها.

## التقنية

- **الواجهة**: Vite 8 · React 19 · TypeScript · Tailwind CSS v4 · Framer Motion · React Router 7 · Lucide
- **الخادم**: Express 5 · `node:sqlite` (بدون قواعد بيانات خارجية) · JWT في كوكي httpOnly · multer للرفع
- **اللغة**: طبقات `ar`/`en` مع دعم الاتجاه (RTL/LTR) تلقائياً، والواجهة الافتراضية عربية.
- **الأمان**: سحب `nosniff`/`X-Frame-Options`/`Referrer-Policy`، حدود لسجلات الدخول، فحص الملفات قبل الحفظ، وتسجيل كل عملية إدارية.
